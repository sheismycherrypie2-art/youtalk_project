# YouTalk Blog

Адаптивная вёрстка блога YouTalk по макету Figma.

## Страницы

- `index.html` — страница блога со списком статей.
- `article.html` — страница статьи с основным контентом и боковым блоком.

## Что реализовано

- Семантическая HTML-разметка: `header`, `main`, `footer`, `section`, `article`, `aside`.
- Классы оформлены по БЭМ-подходу.
- Адаптивная сетка карточек на CSS Grid.
- Адаптив под desktop, tablet и mobile.
- PNG-картинки из выгрузки макета.
- SVG-иконки в папке `assets/icons`.
- Alt-тексты для изображений.
- Hover/focus-состояния для кликабельных элементов.
- Псевдоклассы и псевдоэлементы.
